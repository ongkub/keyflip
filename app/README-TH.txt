KeyFlip สำหรับ Mac — รุ่นทดลอง (beta) 0.3.0

KeyFlip แก้คำที่พิมพ์ผิดภาษาไทย/อังกฤษให้อัตโนมัติระหว่างพิมพ์ และสลับแป้นให้เอง
เช่น ลืมเปลี่ยนเป็นแป้นไทยแล้วพิมพ์ vpkdwxdbo-hk; จะกลายเป็น "อยากไปกินข้าว"
ต้องใช้ macOS 13 ขึ้นไป ใช้ได้ทั้งชิป Apple Silicon (M1 ขึ้นไป) และ Intel

วิธีติดตั้ง
1. ดับเบิลคลิกไฟล์ zip (Safari อาจแตกไฟล์ให้แล้ว) จะได้โฟลเดอร์ KeyFlip-macOS-beta
2. ลาก KeyFlipAuto.app ไปไว้ในโฟลเดอร์ Applications ก่อนเปิดเสมอ
   (ถ้าเปิดจาก Downloads ตรงๆ macOS จะรันจากที่ชั่วคราวและจำสิทธิ์ไม่ได้)
3. เปิดครั้งแรก: macOS เตือนว่าไม่สามารถตรวจสอบแอปได้ (ยังไม่ได้ลงทะเบียนกับ Apple)
   กด เสร็จสิ้น (Done) แล้วเปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย
   (System Settings → Privacy & Security) เลื่อนลงล่างสุด กด "เปิดต่อไป" (Open Anyway)
   และใส่รหัสผ่าน Mac ทำแค่ครั้งแรกครั้งเดียว
4. แอปจะขอสิทธิ์การช่วยการเข้าถึง (Accessibility) ให้กดเปิดการตั้งค่าระบบ
   แล้วเปิดสวิตช์ให้ KeyFlipAuto (ถ้าหน้าต่างไม่ขึ้น ให้ใช้เมนู "ตั้งค่าสิทธิ์ Accessibility…")
   เมื่อเปิดสวิตช์แล้ว แอปจะเริ่มทำงานเองภายในไม่กี่วินาที (ไม่ต้องเปิดแอปใหม่)
5. แหล่งป้อนเข้า: ใน การตั้งค่าระบบ → แป้นพิมพ์ → การป้อนข้อความ → แก้ไข
   (System Settings → Keyboard → Text Input → Edit) ต้องมีทั้ง "ไทย" (ผังเกษมณี)
   และ "ABC" หรือ "U.S." (ยังไม่รองรับผังภาษาไทยอื่น เช่น ปัตตะโชติ)

วิธีใช้งาน
- แอปเป็นไอคอนบนแถบเมนูด้านบนขวา ไม่มีหน้าต่าง แค่พิมพ์ตามปกติ
  เมื่อพิมพ์ผิดภาษา แอปจะแก้คำให้หลังกด Spacebar และสลับภาษาแป้นพิมพ์ให้เอง
- เมนูเมื่อคลิกไอคอน: "แก้ภาษาอัตโนมัติ" (เปิด/ปิด), "แปลงข้อความที่เลือก (⌃⇧Space)" (เปิด/ปิด), บรรทัดสถิติวันนี้, "ล้างคำที่ตั้งไม่ให้แปลง",
  "แจ้งปัญหา…", "เปิดโฟลเดอร์ข้อมูล", "ตั้งค่าสิทธิ์ Accessibility…", "ออก"
- แก้ผิด: กด Backspace ทันทีหลังแปลง หรือแตะ Shift สองครั้ง
  ถ้ากดย้อนคำเดิมซ้ำครั้งที่สอง แอปจะจำไว้ว่าจะไม่แปลงคำนั้นอีก
  (รีเซ็ตรายการนี้ได้ที่ "ล้างคำที่ตั้งไม่ให้แปลง")
- แปลงข้อความที่เลือก: ลากคลุมข้อความในแอปใดก็ได้ แล้วกด Control+Shift+Space (⌃⇧Space) เพื่อแปลงคำที่พิมพ์ผิด (ย้อนกลับด้วย Command+Z)
- เปิดอัตโนมัติเมื่อเปิดเครื่อง: แอปไม่ได้ตั้งตัวเอง ให้ไปที่ การตั้งค่าระบบ → ทั่วไป →
  รายการเข้าสู่ระบบ (System Settings → General → Login Items) แล้วเพิ่ม KeyFlipAuto

ความเป็นส่วนตัว
- ทุกอย่างทำงานในเครื่อง ไม่ส่งสิ่งที่พิมพ์ออกไปไหน
- ไม่ทำงานในช่องรหัสผ่าน และปิดตัวเองในแอป เช่น Terminal, iTerm, VS Code,
  Xcode, JetBrains และ 1Password
- "แจ้งปัญหา…" ส่งเฉพาะสิ่งที่คุณเขียนและข้อมูลเวอร์ชัน โดยคุณจะเห็นทั้งหมดก่อนกดส่ง
  และจะแนบคำที่เพิ่งแปลงไปเฉพาะเมื่อติ๊กเลือกช่องนั้นเท่านั้น

การอัปเดตและถอนการติดตั้ง
- เมื่ออัปเดตเป็นรุ่นใหม่ macOS อาจถามสิทธิ์ใหม่ ให้ไปที่รายการ Accessibility
  ลบ KeyFlipAuto ตัวเก่าออกด้วยปุ่ม − แล้วเปิดแอปใหม่และอนุญาตอีกครั้ง
- ถอนการติดตั้ง: เมนู → "ออก", ลบ KeyFlipAuto.app ออกจาก Applications,
  ลบออกจากรายการ Accessibility และลบโฟลเดอร์
  ~/Library/Application Support/KeyFlipAuto เพื่อลบข้อมูล

พบปัญหาแจ้งได้ผ่านเมนู "แจ้งปัญหา…"
