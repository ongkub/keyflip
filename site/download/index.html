เปิดหน้านี้บนคอมพิวเตอร์

KeyFlip ใช้กับ Mac และ Windows เท่านั้น ส่งลิงก์นี้ไปเปิดบนคอมพิวเตอร์ของคุณ

ส่งทาง LINE

สำหรับ Mac

ตรงกับเครื่องนี้

macOS 13 ขึ้นไป, Apple Silicon และ Intel

KeyFlip-macOS-beta-0.2.0.zip (ไฟล์ zip ขนาด 10.4 MB)

ดาวน์โหลดสำหรับ Mac
ตรวจสอบไฟล์ (SHA-256)

รหัส SHA-256:

90e9f7b6d387a3a17836d5f32320285218a87edb5f2ae88804161149cfb5afda

คำสั่งตรวจสอบใน Terminal:

shasum -a 256 KeyFlip-macOS-beta-0.2.0.zip

สำหรับ Windows

ตรงกับเครื่องนี้

Windows 10 และ 11 แบบ 64 บิต

KeyFlip-Windows-beta-0.2.0.zip (ไฟล์ zip ขนาด 8.4 MB)

ดาวน์โหลดสำหรับ Windows
ตรวจสอบไฟล์ (SHA-256)

รหัส SHA-256:

77443eb3f9908a63228579a391fc1288aa13075cf89aa02fc2313a00231976ce

คำสั่งตรวจสอบใน Command Prompt / PowerShell:

certutil -hashfile KeyFlip-Windows-beta-0.2.0.zip SHA256

เปิดครั้งแรก ทำตามนี้

เครื่องจะเตือนตอนเปิดครั้งแรก เพราะรุ่นทดลองยังไม่ได้ลงทะเบียนกับ Apple และ Microsoft เป็นเรื่องปกติ ทำตามขั้นตอนนี้ครั้งเดียว

สำหรับ Mac

  1. แตกไฟล์ zip ที่ดาวน์โหลดมา
  2. ลาก KeyFlipAuto.app ไปไว้ในโฟลเดอร์ แอปพลิเคชัน (Applications) ก่อนเปิดใช้งานเสมอ (หากเปิดตรงจากโฟลเดอร์ดาวน์โหลด การตั้งค่าสิทธิ์จะไม่ถูกบันทึก)
  3. ดับเบิลคลิกเปิดแอป ระบบ macOS จะแจ้งเตือนว่าไม่สามารถตรวจสอบยืนยันแอปได้ ให้คลิก เสร็จสิ้น (Done)
  4. เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย (System Settings → Privacy & Security) เลื่อนลงมาด้านล่างแล้วคลิก เปิดต่อไป (Open Anyway)
  5. ใส่รหัสผ่านเครื่อง Mac ของคุณเพื่อยืนยัน
  6. เมื่อระบบถามการอนุญาต การช่วยการเข้าถึง (Accessibility) ให้เปิดสวิตช์อนุญาตสำหรับ KeyFlipAuto
  7. KeyFlip จะเริ่มทำงานภายในไม่กี่วินาที และจะเห็นตัวอักษร ก⇄A ที่แถบเมนูด้านบน (ถ้ามี ⚠ ต่อท้าย แปลว่ายังไม่ได้อนุญาตการช่วยการเข้าถึง) (หากต้องการให้เปิดพร้อมเครื่อง ไปที่ การตั้งค่าระบบ → ทั่วไป → รายการเข้าสู่ระบบ เพื่อเพิ่ม KeyFlipAuto ลงในรายการ)

สำหรับ Windows

  1. แตกไฟล์ zip ไว้ที่ใดก็ได้ตามต้องการ (เช่น Documents\KeyFlip) โดยเก็บไฟล์ keyflip.exe ไว้ข้างโฟลเดอร์ models เสมอ
  2. ดับเบิลคลิกเปิดไฟล์ keyflip.exe
  3. หากหน้าต่าง Windows protected your PC ปรากฏขึ้น ให้คลิก More info แล้วเลือก Run anyway
  4. ไอคอนจะปรากฏขึ้นที่ ถาดระบบ (System Tray) บริเวณมุมล่างขวาของหน้าจอ
  5. คลิกขวาที่ไอคอนเพื่อเปิด/ปิดการทำงาน ดูสถิติ และเลือก แจ้งปัญหา…

เปิดแป้นพิมพ์ไทยและอังกฤษ

KeyFlip ต้องเปิดใช้งานทั้งผังแป้นพิมพ์ภาษาไทย (เกษมณี) และภาษาอังกฤษไว้ในเครื่อง:

สำหรับ Mac

ไปที่ การตั้งค่าระบบ → แป้นพิมพ์ → การป้อนข้อความ → แก้ไข → เพิ่ม "ไทย" และ "ABC"

สำหรับ Windows

ไปที่ Settings → Time & language → Language & region แล้วเพิ่มภาษาไทยคู่กับแป้นพิมพ์ Thai Kedmanee โดยคงแป้นพิมพ์ English (US) ไว้

ใช้งานและเลิกใช้

  • การย้อนคำที่แก้ (Undo): กดแป้น Backspace ทันทีหลังจากที่แอปแปลงคำ หรือแตะแป้น Shift สองครั้งติดกัน
  • การปิดชั่วคราว: บน Mac คลิกไอคอนบนแถบเมนูด้านบนเพื่อเปิดหรือปิด ส่วนบน Windows คลิกขวาที่ไอคอนในถาดระบบมุมล่างขวา
  • การถอนการติดตั้ง:
    • Mac: ออกจากแอปผ่านไอคอนบนแถบเมนู ลบแอปออกจากโฟลเดอร์ Applications เอาออกจากรายการ Accessibility และสามารถลบโฟลเดอร์ ~/Library/Application Support/KeyFlipAuto เพิ่มเติมได้
    • Windows: ออกจากแอปผ่านไอคอนในถาดระบบ ลบโฟลเดอร์แอป และสามารถลบโฟลเดอร์ %APPDATA%\KeyFlip เพิ่มเติมได้
