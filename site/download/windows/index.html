สร้างโดย Spark Factor

ทำตามนี้

  1. แตกไฟล์ zip ไว้ที่ใดก็ได้ตามต้องการ (เช่น Documents\KeyFlip) โดยเก็บไฟล์ keyflip.exe ไว้ข้างโฟลเดอร์ models เสมอ
  2. ดับเบิลคลิกเปิดไฟล์ keyflip.exe
  3. หากหน้าต่าง Windows protected your PC ปรากฏขึ้น ให้คลิก More info แล้วเลือก Run anyway
  4. ไอคอนจะปรากฏขึ้นที่ ถาดระบบ (System Tray) บริเวณมุมล่างขวาของหน้าจอ
  5. คลิกขวาที่ไอคอนเพื่อเปิด/ปิดการทำงาน ดูสถิติ และเลือก แจ้งปัญหา…
