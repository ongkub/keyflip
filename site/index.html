พิมพ์ผิดภาษา ไม่ต้องลบพิมพ์ใหม่

ลืมเปลี่ยนภาษาแล้วพิมพ์ออกมาเป็น l;ylfu ใช่ไหม KeyFlip แก้เป็น “สวัสดี” ให้ทันที แล้วสลับแป้นพิมพ์ให้เอง ใช้ได้ทั้งไทยเป็นอังกฤษ และอังกฤษเป็นไทย

ดาวน์โหลดฟรี ดูคลิปการใช้งาน

ใช้ได้บน macOS 13 ขึ้นไป และ Windows 64 บิต รุ่นทดลอง 0.3.0 ฟรีและเปิดโค้ด

ตัวอย่างนี้แปลงทุกตัวอักษรตามแป้น ส่วนแอปจริงจะแก้เฉพาะคำที่พิมพ์ผิดแป้นเท่านั้น

ดูตอนใช้งานจริง

คลิปนี้อัดจากหน้าจอจริงบน Mac ใน Chrome, Notes, Word และ Claude พิมพ์ภาษาไทยตอนแป้นยังเป็นอังกฤษ และพิมพ์ภาษาอังกฤษตอนแป้นเป็นไทย KeyFlip แก้ให้ทั้งสองแบบทันที โดยไม่ต้องกดเปลี่ยนภาษาเอง

iร ลืมเปลี่ยนเป็นไทย: พิมพ์ ihkodkca ได้ ร้านกาแฟ
ไw ลืมเปลี่ยนเป็นอังกฤษ: พิมพ์ ไรดร ได้ wifi

มันรู้ได้ยังไงว่าพิมพ์ผิด

ระหว่างที่คุณพิมพ์ KeyFlip จะอ่านคำล่าสุดพร้อมกันสองแบบ คือแบบที่คุณกดลงไปจริง และแบบที่เป็นปุ่มเดียวกันในอีกภาษาหนึ่ง

ถ้าการอ่านอีกภาษาหนึ่งเป็นคำที่มีความหมายชัดเจน ในขณะที่สิ่งที่คุณเพิ่งพิมพ์ไม่ใช่คำ KeyFlip จะสลับแป้นพิมพ์แล้วแทนที่ด้วยคำที่ถูกต้องให้ทันที แต่ถ้าไม่แน่ใจ แอปจะปล่อยคำนั้นไว้ตามเดิมโดยไม่แตะต้อง

การตรวจจับและตัดสินใจทั้งหมดเกิดขึ้นในเครื่องของคุณทันที ไม่มีการส่งสิ่งที่คุณพิมพ์ออกไปประมวลผลที่อื่น

l;ylfu อ่านเป็นภาษาอังกฤษ → ไม่ใช่คำ
l;ylfu ปุ่มเดียวกันอ่านเป็นภาษาไทย → สวัสดี → แก้ให้

ถ้ามันแก้ผิด

กด Backspace ทันทีหลังมันแปลง หรือแตะ Shift สองครั้ง คำจะกลับเป็นแบบที่คุณพิมพ์ ถ้าย้อนคำเดิมเป็นครั้งที่สอง KeyFlip จะจำไว้และไม่แปลงคำนั้นอีก ล้างรายการนี้ได้จากเมนูของแอป หรือเลือกข้อความแล้วกด Control+Shift+Space (⌃⇧Space บน Mac) หรือ Ctrl+Alt+Space (Windows) เพื่อแปลงข้อความที่พิมพ์ไปแล้วได้ทันที

KeyFlip เห็นอะไร และส่งอะไรออกไป

ระหว่างพิมพ์ KeyFlip เห็น

  • ปุ่มที่คุณกด เพื่อดูว่าคำล่าสุดพิมพ์ผิดแป้นหรือไม่
  • ชื่อแอปที่เปิดอยู่ เพื่อหยุดทำงานในแอปอย่าง Terminal, VS Code และตัวจัดการรหัสผ่าน
  • ไม่ทำงานในช่องรหัสผ่าน

เก็บไว้ในเครื่องของคุณเท่านั้น

  • คำที่ถูกแปลงหรือที่คุณย้อนกลับ พร้อมชื่อแอปที่พิมพ์
  • จำนวนคำที่พิมพ์และที่แก้ในแต่ละวัน
  • ข้อความอื่นที่พิมพ์ไม่ถูกเก็บ

ส่งออกไปนอกเครื่อง

  • ไม่มี ยกเว้นตอนที่คุณเปิด “แจ้งปัญหา…” แล้วกดส่งเอง ซึ่งส่งเฉพาะสิ่งที่เห็นในหน้าต่างรายงาน

ตรวจดูได้เองในโค้ด: ตัวอ่านแป้นบน Mac, ตัวอ่านแป้นบน Windows, ตัวรับรายงานปัญหา

ก่อนเปิดครั้งแรก

รุ่นทดลองนี้ยังไม่ได้ลงทะเบียนกับ Apple และ Microsoft เครื่องจึงเตือนตอนเปิดครั้งแรก เป็นเรื่องปกติ หน้าดาวน์โหลดมีวิธีผ่านทีละขั้น และต้องเปิดแป้นพิมพ์ทั้งไทย (เกษมณี) และอังกฤษไว้ในเครื่อง

ไปหน้าดาวน์โหลด

คำถามที่พบบ่อย

KeyFlip อ่านทุกอย่างที่ฉันพิมพ์หรือเปล่า +

ไม่อ่านทุกอย่าง KeyFlip เฝ้าดูการกดปุ่มเพื่อตัดสินใจเฉพาะคำล่าสุดที่คุณกำลังพิมพ์เท่านั้น เมื่อแปลงคำหรือเมื่อคุณกดย้อนคำ ข้อมูลคำเหล่านั้นจะถูกเก็บไว้เฉพาะในเครื่องของคุณเพื่อการเรียนรู้ จะไม่มีการส่งข้อความใด ๆ ออกนอกเครื่องเว้นแต่คุณจะกดส่งรายงานปัญหาด้วยตัวเอง และโค้ดทั้งหมดเปิดเผยให้ตรวจสอบได้

ทำไมเครื่องเตือนตอนเปิด +

เนื่องจากเป็นรุ่นทดลอง (Beta) ที่ยังไม่ได้ลงทะเบียนใบรับรองนักพัฒนากับ Apple และ Microsoft ทั้งสองระบบจึงขึ้นข้อความเตือนความปลอดภัยตามปกติ คุณสามารถดูขั้นตอนการอนุญาตเปิดใช้งานทีละขั้นอย่างละเอียดได้ในหน้าดาวน์โหลด

ใช้กับแป้นแบบไหนได้บ้าง +

ปัจจุบันรองรับแป้นพิมพ์ภาษาไทยแบบเกษมณี (Kedmanee) คู่กับภาษาอังกฤษแบบมาตรฐาน (US / ABC) สำหรับแป้นพิมพ์ปัตตะโชติ (Pattachote) ยังไม่รองรับในรุ่นนี้

ใช้ในแอปไหนได้บ้าง +

ใช้งานได้ในเกือบทุกแอปที่คุณพิมพ์ข้อความ เช่น เว็บบราวเซอร์, LINE, Microsoft Word, โปรแกรมอีเมล และแอปแช็ตทั่วไป โดย KeyFlip จะหยุดทำงานโดยอัตโนมัติในช่องกรอกรหัสผ่าน แอป Terminal ตัวแก้ไขโค้ด และโปรแกรมจัดการรหัสผ่าน

แปลงข้อความที่พิมพ์ไปแล้วได้ไหม +

ทำได้ เพียงเลือกข้อความในแอปใดก็ได้ แล้วกด Control+Shift+Space (⌃⇧Space บน Mac) หรือ Ctrl+Alt+Space (Windows) KeyFlip จะแทนที่ข้อความด้วยคำที่แปลงภาษาให้ทันที โดยจะแปลงเฉพาะคำที่พิมพ์ผิดภาษา หรือสลับทั้งข้อความหากทุกคำถูกต้องอยู่แล้ว สามารถกดย้อนกลับ (Undo) ได้ด้วย Command+Z หรือ Ctrl+Z ในแอปนั้น ฟังก์ชันนี้ทำงานได้แม้ปิดการแก้คำอัตโนมัติไว้ ยกเว้นในช่องรหัสผ่านหรือแอปที่ปิดการทำงานไว้ การทำงานจะใช้คลิปบอร์ดชั่วคราวและคืนค่าเดิมให้ทันที พร้อมระบุไม่ให้โปรแกรมประวัติคลิปบอร์ดบันทึกข้อความ เปิดหรือปิดได้จากเมนู “แปลงข้อความที่เลือก” ในแอป

ฟรีจริงไหม +

ฟรีอย่างสมบูรณ์ ไม่มีค่าใช้จ่ายและไม่มีโฆษณา ตัวแอปเป็นโครงการโอเพนซอร์สภายใต้สัญญาอนุญาต MIT

ปิดชั่วคราวได้ไหม +

ปิดชั่วคราวได้ตลอดเวลา บน Mac คลิกไอคอนบนแถบเมนูด้านบนแล้วเลือก “แก้ภาษาอัตโนมัติ” เพื่อเปิด/ปิด ส่วนบน Windows ให้คลิกขวาที่ไอคอนในถาดระบบ (System Tray)

เจอปัญหาจะแจ้งยังไง +

คุณสามารถเปิดเมนูของแอปแล้วเลือก “แจ้งปัญหา…” โดยคุณจะมองเห็นข้อมูลทั้งหมดที่จะส่งก่อนกดส่งเสมอ หรือสามารถเปิด Issue ในคลังโค้ดบน GitHub ได้โดยตรง
