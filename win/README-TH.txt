KeyFlip สำหรับ Windows — รุ่นทดลอง (beta) 0.3.1

KeyFlip แก้คำที่พิมพ์ผิดภาษาไทย/อังกฤษให้อัตโนมัติระหว่างพิมพ์ และสลับแป้นให้เอง
เช่น ลืมเปลี่ยนเป็นแป้นไทยแล้วพิมพ์ vpkdwxdbo-hk; จะกลายเป็น "อยากไปกินข้าว"

วิธีเปิด
1. แตกไฟล์ zip นี้ไว้ที่ไหนก็ได้ (เช่น Documents\KeyFlip) ให้ keyflip.exe อยู่คู่กับโฟลเดอร์ models
2. ดับเบิลคลิก keyflip.exe
   ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด More info → Run anyway
   (เพราะรุ่นทดลองยังไม่ได้ซื้อใบรับรองจาก Microsoft)
3. จะมีไอคอนที่ถาดระบบมุมขวาล่าง คลิกขวาเพื่อเปิด/ปิด ดูสถิติ หรือ "แจ้งปัญหา…"
4. ต้องเปิดแป้นพิมพ์ทั้ง Thai Kedmanee และ English (US) ไว้ใน Windows
KeyFlip จะเปิดพร้อม Windows โดยอัตโนมัติ ปิดได้ที่เมนูถาดระบบ "เปิดพร้อมเครื่อง"; หลังย้ายหรืออัปเดตโฟลเดอร์ ให้เปิด keyflip.exe ในตำแหน่งใหม่หนึ่งครั้งเพื่อย้ายรายการเริ่มต้น

ความเป็นส่วนตัว
- ทุกอย่างทำงานในเครื่อง ไม่ส่งสิ่งที่พิมพ์ออกไปไหน
- ไม่ทำงานในช่องรหัสผ่าน และในโปรแกรมอย่าง Terminal, VS Code, ตัวจัดการรหัสผ่าน
- "แจ้งปัญหา…" ส่งเฉพาะข้อความที่คุณเขียนและข้อมูลเวอร์ชัน คุณเห็นทุกอย่างก่อนกดส่ง

แก้ผิด: กด Backspace ทันทีหลังมันแปลง หรือแตะ Shift สองครั้ง
แปลงข้อความที่พิมพ์ไปแล้ว: ลากเลือกข้อความ แล้วกด Ctrl+Alt+Space (ย้อนด้วย Ctrl+Z) เปิด/ปิดได้ที่เมนูถาดระบบ
ปิดโปรแกรม: คลิกขวาไอคอนที่ถาดระบบ → ออก
ถอนการติดตั้ง: เอาติ๊ก "เปิดพร้อมเครื่อง" ออกก่อน แล้วคลิก "ออก" และลบโฟลเดอร์ (ถ้าลืม รายการเริ่มต้นที่ค้างอยู่จะชี้ไปไฟล์ที่ไม่มีแล้ว ไม่มีผลอะไร ปิดได้ใน Task Manager → Startup apps)
