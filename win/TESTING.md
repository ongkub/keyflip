# ทดสอบ KeyFlip บน Windows ใน 10 นาที

ใช้ Windows 10/11 ที่มีแป้นพิมพ์ English และ Thai Kedmanee แล้วทดสอบด้วยข้อความสมมติ
จดผลผ่าน/ไม่ผ่านแต่ละข้อ ไม่ต้องติดตั้ง Rust หรือใช้คำสั่งใด ๆ

## เปิดพร้อมเครื่อง

- เปิด KeyFlip ครั้งแรก ตรวจว่าเมนูถาดระบบติ๊ก “เปิดพร้อมเครื่อง” และ Task Manager → Startup apps แสดง KeyFlip
- sign out แล้ว sign in ตรวจว่า KeyFlip เปิดเอง
- เอาติ๊กออก ตรวจว่ารายการถูกลบ; ติ๊กกลับ ตรวจว่ารายการถูกเพิ่ม
- ปิด KeyFlip, ปิดใช้งาน KeyFlip ใน Task Manager → Startup apps แล้วเปิด KeyFlip ใหม่ ตรวจว่าไม่เปิดใช้งานรายการกลับเองและเมนูไม่ถูกติ๊ก
- คัดลอกโฟลเดอร์ KeyFlip ไปอีกตำแหน่งแล้วเปิด keyflip.exe ใหม่ ตรวจว่า Startup apps แสดงตำแหน่งใหม่

## นาที 0–2: เปิดใช้งาน

1. แตก ZIP ทั้งหมดไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Downloads\KeyFlip
2. ข้าง `keyflip.exe` ต้องมีโฟลเดอร์ `models` ซึ่งมีไฟล์ `th.kfm` และ `en.kfm` อยู่ภายใน
   (ไฟล์ exe จาก CI อย่างเดียวไม่มีโมเดล ต้องนำโมเดลที่ผู้ส่งให้มาวางเพิ่ม)
3. เปิด `keyflip.exe` ถ้า SmartScreen ขึ้น ให้กด **More info → Run anyway**
4. หาไอคอน KeyFlip ในถาดระบบข้างนาฬิกา อาจอยู่ในปุ่มลูกศรขึ้น คลิกขวาแล้วตรวจว่า
   **แก้ภาษาอัตโนมัติ** มีเครื่องหมายถูก เปิด exe ซ้ำต้องไม่มีไอคอนเพิ่ม
5. ถ้ามีข้อความเตือนโมเดลหาย/ไม่มีแป้นไทย ให้แก้ตามข้อความแล้วออกจากแอปและเปิดใหม่
   เพิ่มแป้นไทยได้ที่ Settings → Time & language → Language & region → Thai → Keyboards → Thai Kedmanee

## นาที 2–4: Notepad และการย้อน

- เปิด Notepad ใหม่ ตั้งแป้นเป็น English แล้วพิมพ์ `l;ylfu` ตามด้วย Space
  ต้องได้ `สวัสดี ` และแป้นเปลี่ยนเป็นไทย อาจแก้ก่อนกด Space ตามโมเดล
- ตั้งแป้นเป็นไทย แล้วกดปุ่มภาษาอังกฤษตามตัวอักษร `hello` และ Space
  ข้อความที่พิมพ์ผิดผัง (`้ำสสน`) ควรเปลี่ยนเป็น `hello ` พร้อมแป้นอังกฤษ
- พิมพ์คำไทย/อังกฤษที่ถูกผังอยู่แล้ว ต้องไม่เปลี่ยนคำที่ถูกต้องทุกคำ
- หลังเห็นการแก้ ให้กด Backspace เป็นปุ่มแรก ต้องได้ข้อความก่อนแปลงกลับมา
  Space ที่อยู่ท้ายคำควรยังอยู่ ไม่หายทั้งบรรทัด
- ทำให้เกิดการแก้อีกครั้ง แล้วแตะ Shift สองครั้งเร็ว ๆ (ปล่อยแต่ละครั้งภายใน ¼ วินาที)
  ต้องย้อนกลับได้ จากนั้นลองพิมพ์ตัวเล็กเพื่อตรวจว่า Shift ไม่ค้าง
- ลอง Shift ค้าง/Shift สองครั้งช้า ๆ/Shift แล้วพิมพ์อักษรหรือคลิก แล้ว Shift อีกครั้ง
  ต้องไม่ย้อนคำ การย้อนด้วย Shift จะจำคำไว้ในรายการไม่ให้แปลง
- คลิกขวาไอคอน → **ล้างคำที่ตั้งไม่ให้แปลง (N)** ก่อนใช้คำเดิมทดสอบรอบถัดไป
  การย้อนด้วย Backspace สองครั้งสำหรับคำเดียวกันจะจำคำเช่นกัน

## นาที 4–6: โปรแกรมที่ใช้ประจำ

ลองคำผิดผังแบบข้างต้นในแต่ละที่ แล้วจดว่าผ่านหรือมีตัวอักษรตก/ซ้ำ:

- Microsoft Word หรือช่องเขียนเอกสาร Google Docs
- ช่องพิมพ์แชต LINE (ยังไม่ต้องส่งข้อความ)
- แถบที่อยู่ของ Edge/Chrome (พิมพ์อย่างเดียว ไม่ต้องเปิดเว็บตามข้อความ)

ลอง Space, Tab, Enter, Backspace และลองย้ายเคอร์เซอร์ด้วยลูกศรหรือคลิกก่อนพิมพ์คำใหม่
แอปต้องไม่ลบข้อความจากตำแหน่งเก่า หลังใช้ Ctrl+C/Ctrl+V หรือ Alt+Tab ต้องเริ่มจำคำใหม่
ช่องที่ Windows อ่านสถานะความปลอดภัยไม่ได้จะไม่แก้คำ

## นาที 6–8: รหัสผ่าน โปรแกรมสิทธิ์สูง และผังแป้น

- เปิดช่องรหัสผ่านในหน้าเข้าสู่ระบบที่เชื่อถือได้ พิมพ์ **รหัสสมมติที่ไม่ใช่รหัสจริง** ด้วยปุ่ม
  `l;ylfu` ตามด้วย Space, Backspace และ Shift สองครั้ง: แอปต้องไม่แก้หรือย้อนข้อความ
  ถ้ามีปุ่มแสดงรหัสให้ตรวจด้วยรหัสสมมติเท่านั้น ตัวนับแก้/ย้อนต้องไม่เพิ่ม
- ไปช่องธรรมดา แล้วกลับช่องรหัสผ่านสลับกันเร็ว ๆ ลองซ้ำอีกครั้ง ต้องไม่แก้ในช่องรหัสผ่าน
- เปิดโฟลเดอร์ข้อมูลจากเมนู ตรวจ `events.jsonl` ด้วย Notepad:
  ต้องไม่มีคำรหัสสมมติที่พิมพ์ในช่องรหัสผ่าน (ถ้าไม่เคยมีการแก้เลย ไฟล์นี้อาจยังไม่มี)
- เปิด Notepad ด้วย **Run as administrator** แล้วลองคำผิดผัง แอปที่เปิดปกติอาจส่งข้อความแทนไม่ได้
  ต้องไม่ลบ/เติมข้อความครึ่ง ๆ กลาง ๆ และกลับ Notepad ปกติแล้วยังใช้งานต่อได้
  หากมีข้อความหาย ให้รายงานทันทีพร้อมลำดับปุ่ม
- สลับไทย/อังกฤษเองระหว่างพิมพ์คำ ต้องไม่เอาคำก่อนเปลี่ยนผังมารวมแก้
  ถ้ามีภาษาอื่นหรือ Thai Pattachote ให้เลือกแล้วพิมพ์: ต้องไม่แก้ข้อความ
- ลองใน Terminal/PowerShell และ VS Code: ค่าเริ่มต้นต้องไม่แก้ข้อความ

## นาที 8–10: เมนูและการจำค่า

- ปิดเครื่องหมาย **แก้ภาษาอัตโนมัติ** แล้วลองคำผิดผัง ต้องไม่แก้ เปิดกลับแล้วต้องทำงาน
- ตรวจบรรทัด **วันนี้: พิมพ์ N คำ · แก้ให้ X · ย้อน Y** ว่าเพิ่มหลังการทดสอบ
  จำนวนคำเพิ่มเมื่อจบคำด้วย Space/Tab/Enter ตัวนับใช้วัน UTC เช่นเดียวกับ macOS
- เปิดโฟลเดอร์ข้อมูล ต้องอยู่ที่ `%APPDATA%\KeyFlip\` มี `settings.json`, `stats.json`
  และมี `never.txt` หลังจำคำ/ล้างรายการ กับ `events.jsonl` หลังแก้หรือย้อน
- กด **ออก** แล้วเปิดใหม่ การตั้งค่าและรายการคำต้องยังอยู่ กด **ออก** อีกครั้ง ไอคอนต้องหาย
- หากต้องการปรับโปรแกรมยกเว้น: ออกจากแอป เปิด `settings.json` ด้วย Notepad แก้รายการ
  `excludedProcesses` เป็นชื่อไฟล์ exe (ไม่ต้องใส่โฟลเดอร์) แล้วเปิดแอปใหม่
  โมเดลส่วนตัวใช้ `%APPDATA%\KeyFlip\models\th.kfm` และ `en.kfm` ต้องมีครบทั้งคู่

## เพิ่มใน 0.3.0: แปลงข้อความที่เลือก (Ctrl+Alt+Space)

- ก่อนเริ่ม กด Win+Shift+S จับภาพหน้าจอเล็กๆ ไว้ในคลิปบอร์ด (ใช้เช็กว่าคลิปบอร์ดเดิมกลับมา)
- ใน Notepad ปิดเครื่องหมาย **แก้ภาษาอัตโนมัติ** ที่ถาดระบบ แล้วพิมพ์ `l;ylfu vpkdwxdbo-hk;` ตอนแป้นเป็น English
- ลากเลือกทั้งบรรทัด กด **Ctrl+Alt+Space** ต้องได้ `สวัสดี อยากไปกินข้าว` และแป้นสลับเป็นไทย
  (ปุ่มนี้ใช้ได้แม้ปิดการแก้อัตโนมัติไว้)
- กด Ctrl+Z ต้องกลับเป็นข้อความเดิมในครั้งเดียว
- เปิด Paint แล้วกด Ctrl+V ต้องได้ภาพที่จับไว้ตอนแรก ไม่ใช่ข้อความ
- กด Win+V (ประวัติคลิปบอร์ด) ข้อความที่แปลงแล้วต้องไม่อยู่ในรายการ
- คลิกให้ไม่มีอะไรถูกเลือก แล้วกด Ctrl+Alt+Space ต้องไม่เกิดอะไรขึ้น
- พิมพ์ `นัดลูกค้า ` แล้วสลับเป็นไทยพิมพ์ `meeting` (จะได้ `ทำำะรืเ`) เลือกทั้งบรรทัดแล้วกด Ctrl+Alt+Space
  ต้องได้ `นัดลูกค้า meeting` (คำที่ถูกอยู่แล้วต้องไม่เปลี่ยน)
- ลองซ้ำใน Chrome (ช่องค้นหาหรือกล่องข้อความ) และ Word
- ในช่องรหัสผ่านของเว็บ กด Ctrl+Alt+Space ต้องไม่เกิดอะไรขึ้น
- คลิกขวาที่ถาดระบบ ปิด **แปลงข้อความที่เลือก (Ctrl+Alt+Space)** แล้วลองอีกครั้ง ต้องไม่แปลง
  เปิดกลับก่อนจบ และออกแล้วเปิดแอปใหม่ ค่าที่ตั้งต้องยังอยู่

## ส่งผลกลับให้ผู้พัฒนา

## แจ้งปัญหา

- คลิกขวาไอคอน KeyFlip แล้วเลือก **แจ้งปัญหา…** พิมพ์ข้อความสมมติในรายละเอียด
- ตรวจว่าปุ่ม **ส่ง** ปิดอยู่เมื่อข้อความว่าง และตัวอย่าง JSON เปลี่ยนตามข้อความ/ข้อมูลติดต่อ
- ส่งรายงานหนึ่งครั้งโดยไม่เลือก **แนบคำที่แอปแปลงล่าสุด** ตรวจว่าตัวอย่างไม่มี `recent_words`
- เปิดหน้าต่างอีกครั้ง เลือกช่องแนบคำ แล้วส่งอีกหนึ่งครั้ง ตรวจว่ามีเฉพาะคำที่แอปแปลงหรือย้อนล่าสุด ไม่เกิน 10 รายการ
- ใช้ข้อความ/ข้อมูลติดต่อสมมติเท่านั้น; ตรวจตัวอย่าง JSON ให้แน่ใจก่อนกดส่ง

แจ้ง Windows รุ่น/ภาษา, รุ่น KeyFlip หรือชื่อ ZIP, โปรแกรมและรุ่นที่ใช้, ผังแป้นก่อนพิมพ์,
ปุ่มที่กดตามลำดับ, สิ่งที่คาดกับสิ่งที่เกิดจริง และว่าปัญหาเกิดซ้ำได้กี่ครั้ง
แนบภาพหรือคลิปด้วยข้อความสมมติ หากส่ง `settings.json`, `stats.json`, `events.jsonl`, `never.txt`
ให้ตรวจข้อมูลส่วนตัวก่อนเสมอ ไม่ต้องส่งรหัสผ่านจริง

ผู้พัฒนายังต้องรันทดสอบรายการนี้บน Windows จริง การ compile บน macOS ยืนยันพฤติกรรมสดไม่ได้

## จุดที่ต้องสังเกตเป็นพิเศษ (จากการรีวิวโค้ด)
- หลังแอปแปลงคำให้ ภาษาแป้นพิมพ์เปลี่ยนตามจริงไหม โดยเฉพาะใน LINE, Discord, VS Code และแอปที่สร้างด้วย Electron
  ถ้าคำถูกแปลงแต่แป้นไม่สลับ ให้แจ้งชื่อแอปมาด้วย
- กด Caps Lock สลับเร็วๆ แล้วพิมพ์ต่อทันที ตัวอักษรที่ออกมาถูกตัวพิมพ์ใหญ่/เล็กไหม
